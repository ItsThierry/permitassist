# Permit Rule Engine Part 1 evidence

This directory is generated by `scripts/generate_permit_rule_engine_part1_evidence.py`.
All files are deterministic: no timestamps, network calls, or mutable runtime data are used.

- `cell_census.jsonl`: all 2,162 v2.4 cells, request-time-equivalent validation, strict depth/coverage classification, and evidence hashes.
- `family_depth_census.csv`: aggregate permit/authority depth by project family and strict classification.
- `authority_census.csv`: every per-family authority row exposed by DecisionEnvelope.
- `jurisdiction_census.csv`: jurisdiction boundary inventory.
- `evidence_effective_date_conflicts.json`: deterministic source-date/hash, verdict, authority, and jurisdiction conflicts.
- `frozen_replay_envelopes.jsonl`: full envelope/observation for every synthetic frozen contract case plus byte-parity hashes.
- `divergence_ledger.jsonl`: structured divergence taxonomy rows for the frozen contract corpus.
- `summary.json`: gate totals and immutable input hashes.
- `manifest.json`: hashes of every generated artifact.

The corpus explicitly identifies itself as synthetic contract replay data; it is not represented as production or historical customer evidence.
